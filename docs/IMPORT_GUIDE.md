# 批量导入歌曲指南

## 📥 如何导入你的历史歌曲

### 方法一：通过仪表盘导入

1. 打开小程序，进入**仪表盘**页面
2. 点击**"批量导入历史歌曲"**按钮
3. 在导入页面预览要导入的歌曲列表
4. 点击**"开始导入"**按钮
5. 确认导入操作
6. 等待导入完成，查看导入结果

### 方法二：直接访问导入页面

1. 在小程序中导航到：`pages/settings/data-import/data-import`
2. 或通过代码跳转：
   ```javascript
   wx.navigateTo({
     url: '/pages/settings/data-import/data-import'
   })
   ```

## ⚙️ 导入设置

- **状态**：所有歌曲默认设置为"已完成"
- **熟练度**：默认5星
- **难度**：默认3/5
- **标签**：默认包含"弹唱"和"cover"
- **段落掌握**：所有段落（Intro、Verse、Chorus、Bridge）默认已掌握
- **进度**：100%（因为所有段落已掌握）

## 🔄 重复导入

- 如果歌曲已存在（根据歌曲名判断），将自动跳过
- 不会覆盖已有歌曲的数据
- 只会导入不存在的歌曲

## 📝 自定义导入

如果需要修改导入的歌曲列表，可以编辑：

`pages/settings/data-import/data-import.js` 文件中的 `INITIAL_SONGS` 数组

或

`data/initial-songs.json` 文件

## 💡 提示

- 导入后可以随时编辑每首歌曲的详细信息
- 日期字段会作为"预期发布日期"保存
- 建议导入后检查并完善每首歌曲的信息（如调性、变调夹位置等）
