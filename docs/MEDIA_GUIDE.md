# 视频和乐谱管理指南

## 📹 演示视频功能

### 上传演示视频

1. 进入歌曲详情页
2. 找到"演示视频"区域
3. 点击右上角的"+ 上传"按钮
4. 选择视频来源：
   - **相册**：从手机相册选择已有视频
   - **拍摄**：直接拍摄新视频
5. 选择视频后自动上传（视频限制：最大100MB，最长60秒）
6. 上传成功后，视频会显示在列表中

### 播放视频

- 点击视频缩略图即可播放
- 支持全屏播放
- 支持播放控制（播放/暂停/进度条）

### 删除视频

- 点击视频右侧的"删除"按钮
- 确认删除后，视频文件和数据都会被删除

## 🎼 乐谱功能

### 上传乐谱

1. 进入歌曲详情页
2. 找到"乐谱"区域
3. 点击右上角的"+ 上传"按钮
4. 选择图片来源：
   - **相册**：从手机相册选择乐谱图片
   - **拍摄**：直接拍摄乐谱照片
5. 选择图片后自动上传（图片限制：最大10MB）
6. 上传成功后，乐谱会显示在列表中

### 查看乐谱

- 点击乐谱缩略图即可全屏查看
- 支持图片缩放和滑动查看
- 可以查看多张乐谱（左右滑动切换）

### 删除乐谱

- 点击乐谱右侧的"删除"按钮
- 确认删除后，乐谱文件和数据都会被删除

## 💡 使用建议

### 视频建议

- **演示视频**：录制你演奏这首歌曲的完整版本
- **练习视频**：记录练习过程中的关键片段
- **演出视频**：保存现场演出的精彩瞬间
- **教学视频**：如果你在教别人，可以录制教学视频

### 乐谱建议

- **原版乐谱**：保存歌曲的原始乐谱
- **改编乐谱**：保存你改编后的版本
- **和弦谱**：保存简化的和弦谱
- **指法谱**：保存详细的指法标注

## 📱 文件存储说明

### 当前存储方式

- 文件存储在**本地设备**的临时目录
- 文件路径保存在歌曲数据中
- 卸载小程序会清除所有文件

### 注意事项

⚠️ **重要提示**：
- 本地存储的文件可能在清理缓存时丢失
- 建议定期备份重要视频和乐谱
- 后续版本将支持云存储，文件更安全

### 升级建议

如果需要更稳定的存储，建议：
1. 使用微信云开发存储
2. 或使用第三方云存储服务（如七牛云、阿里云OSS等）
3. 定期导出重要文件到手机相册

## 🔧 技术限制

### 视频限制
- 最大文件大小：100MB
- 最长时长：60秒（可在代码中调整）
- 支持格式：MP4

### 图片限制
- 最大文件大小：10MB
- 支持格式：JPG、PNG

## 🎯 最佳实践

1. **定期备份**：重要视频和乐谱建议保存到手机相册
2. **命名规范**：系统会自动命名，但建议在备注中说明视频/乐谱的内容
3. **分类管理**：使用标签功能区分不同类型的视频（如：演示、练习、演出）
4. **定期清理**：删除不需要的视频和乐谱，节省存储空间
