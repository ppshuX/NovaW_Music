# 云开发集成指南

## 📌 当前情况说明

**重要提示**：当前版本使用**本地存储**，这意味着：
- ✅ 数据存储在本地设备，速度快，无需网络
- ❌ 分享给朋友后，朋友看到的是**他们自己的数据**，不是你的
- ❌ 卸载小程序会丢失所有数据
- ❌ 无法跨设备同步

## 🚀 解决方案：集成微信云开发

要实现"别人查看我的数据"，需要将数据存储到云端。

### 方案一：微信云开发（推荐）

微信云开发是微信官方提供的后端服务，无需搭建服务器。

#### 1. 开通云开发

1. 在微信开发者工具中，点击"云开发"按钮
2. 开通云开发环境
3. 创建环境（选择免费版即可）
4. 获取环境ID（Environment ID）

#### 2. 初始化云开发

在 `app.js` 中取消注释并配置：

```javascript
// app.js
App({
  onLaunch() {
    // 初始化云开发
    if (!wx.cloud) {
      console.error('请使用 2.2.3 或以上的基础库以使用云能力')
    } else {
      wx.cloud.init({
        env: 'your-env-id', // 你的云开发环境ID
        traceUser: true,
      })
    }
    
    this.initStorage()
  },
  // ...
})
```

#### 3. 创建云数据库集合

在云开发控制台创建以下集合：
- `songs` - 歌曲数据
- `practice_logs` - 练习记录
- `posts` - 动态数据
- `user_profiles` - 用户公开资料

#### 4. 修改存储工具

将 `utils/storage.js` 改为使用云数据库：

```javascript
// 示例：获取歌曲列表
export function getSongs() {
  return new Promise((resolve, reject) => {
    wx.cloud.database().collection('songs')
      .where({
        _openid: '{openid}' // 自动获取当前用户
      })
      .get()
      .then(res => {
        resolve(res.data)
      })
      .catch(reject)
  })
}
```

### 方案二：自建后端API

如果需要更多控制，可以搭建自己的后端服务器。

## 💡 当前版本的替代方案

在集成云开发之前，你可以：

### 1. 截图分享
- 在动态页面截图分享
- 在歌曲详情页截图分享

### 2. 导出数据
- 导出为JSON文件
- 通过其他方式分享（微信、邮件等）

### 3. 生成小程序码
- 使用小程序码分享（但数据仍然是本地的）

## 🔄 迁移计划

如果决定升级到云开发：

1. **数据迁移**：需要将现有本地数据导入到云数据库
2. **代码修改**：修改所有存储相关的工具函数
3. **文件存储**：视频和乐谱需要使用云存储
4. **权限控制**：设置数据库权限（公开读取，仅自己可写）

## 📝 注意事项

- 云开发有免费额度，超出后需要付费
- 需要配置数据库权限规则
- 文件存储也需要配置权限

---

**建议**：如果只是个人使用，本地存储完全够用。如果需要分享给他人查看，再考虑升级到云开发。
